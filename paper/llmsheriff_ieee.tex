\begin{abstract}
Current observability systems expose execution events but do not explicitly indicate
whether an autonomous agent is still making meaningful progress toward its goal. As a
result, developers struggle to distinguish productive execution, temporary recovery,
prolonged waiting, and silent failure. This paper presents LLMSheriff, an exploratory
prototype that investigates \emph{behavioral state inference} from execution traces using
hybrid rule-based and LLM analysis. Eight coarse states---Planning, Executing, Waiting,
Recovering, Stalled, Abandoned, Completed, and Failed---are inferred in parallel. Analyzer
\emph{agreement} is treated as an interpretable confidence indicator; \emph{disagreement}
is surfaced as a diagnostic cue for human inspection rather than forced resolution.
On a controlled synthetic corpus of 100 labelled traces (primary hybrid run on the AWS
programme environment), the rule engine reaches 96\% accuracy and the LLM judge 66\%;
when both agree ($n{=}64$), accuracy relative to synthetic labels is 98.4\%. These results
demonstrate feasibility under controlled conditions; they do not establish generalisation
to production agent systems. The contribution is a reproducible hybrid approach to
behavioral diagnosis above conventional observability, not a claim of universal
superiority over existing platforms.
\end{abstract}

\begin{IEEEkeywords}
agentic AI, execution monitoring, intent inference, goal satisfaction, behavioral observability
\end{IEEEkeywords}

\section{Introduction}

Autonomous AI agents orchestrate multi-step workflows involving tool calls, retries,
external dependencies, and long idle periods. Standard observability outputs---logs,
latency metrics, retry counts, and exit codes---record \emph{what} happened during
execution. They rarely answer whether the agent is still making meaningful progress toward
its assigned goal.

This gap matters in practice. An agent may run without errors while making no forward
progress: repeating the same search, polling indefinitely, or drifting after an early
failure. Conversely, an agent may encounter setbacks and still recover by adopting a new
strategy. A monitoring layer that only detects hard failures cannot separate productive
execution, temporary recovery, prolonged waiting, and silent failure---leaving developers
uncertain whether to wait, intervene, or declare success.

Existing observability platforms emphasize execution traces, metrics, and debugging views.
This paper investigates a complementary question: \emph{behavioral state inference for
runtime diagnosis}. LLMSheriff is a research prototype that maps traces to coarse
behavioral states using a hybrid of deterministic rules and an LLM behavioral judge. A
central design choice is that the system does not attempt to recover an agent's true
internal intentions. Instead, it infers \emph{behavioral intent} from externally
observable events---a weaker but tractable formulation. Critically, when the two analyzers
disagree, the conflict is preserved as an uncertainty signal rather than suppressed.

\paragraph{Research question.}
Can hybrid rule-based and LLM-based behavioral inference improve the diagnosis of
autonomous AI agent execution traces, and can agreement/disagreement serve as an
interpretable confidence signal?

\paragraph{Contributions.}
\begin{itemize}
\item A hybrid inference pipeline that produces explainable behavioral states from traces,
with evidence summaries and intervention recommendations.
\item An explicit agreement/disagreement mechanism in which analyzer conflict is treated as
a first-class diagnostic output for human review.
\item A reproducible synthetic evaluation that tests the hypotheses below under controlled
conditions, with transparent limitations.
\end{itemize}

\paragraph{Hypotheses.}
\begin{itemize}
\item \textbf{H1:} A hybrid rule+LLM behavioral inference framework achieves higher
behavioral state prediction performance than either rule-based or LLM-only inference on
the evaluation dataset.
\item \textbf{H2:} Agreement between rule-based and LLM inference serves as an
interpretable confidence indicator, while disagreement identifies cases that warrant
human inspection.
\end{itemize}

We do not claim that LLMSheriff is the best agent observability system. We claim that this
behavioral inference approach is useful and promising under the evaluation performed.

\section{Related Work}

\subsection{AI Observability and Tracing}

Platforms such as LangSmith~\cite{langsmith}, Langfuse~\cite{langfuse}, and
AgentOps~\cite{agentops} provide trace storage, latency analysis, token accounting, and
debugging views for LLM applications. OpenTelemetry~\cite{otel} standardises distributed
tracing across services. These tools excel at reconstructing execution paths and
surfacing failures. They do not, by default, infer goal-level behavioral states for
wait-versus-intervene decisions.

\subsection{Agent Monitoring and Oversight}

Recent work on LLM agents emphasises tool-using workflows~\cite{yao2023react} and
self-reflective repair loops~\cite{shinn2023reflexion}. Oversight research often targets
unsafe tool calls, hallucinated actions, policy violations, and structured provenance for
accountability. Complementary evaluation research uses LLMs as judges of response
quality~\cite{zheng2023judging}. LLMSheriff differs by targeting \emph{progress
semantics} on execution traces: whether behaviour still appears goal-directed rather than
merely error-free, policy-compliant, or locally high-quality. An agent that loops safely
can still fail its user.

\subsection{Goal Recognition and Runtime Verification}

Goal-oriented requirements engineering treats systems in terms of goals and obstacles to
satisfaction~\cite{horkoff2016,dardenne1993}. Plan and goal recognition infer intentions
from observed behaviour~\cite{carberry2001}. Runtime verification checks formal properties
during execution~\cite{leucker2009}. LLMSheriff applies a lightweight, pragmatic variant
of these ideas to LLM-agent traces: coarse state classification with hybrid symbolic and
LLM judgement, rather than full plan reconstruction or temporal-logic specifications.

\subsection{Positioning}

Existing work focuses on observability, tracing, agent scaffolding, evaluation, or safety.
Our work focuses on behavioral state inference for runtime diagnosis, with
agreement/disagreement between analyzers as an interpretable confidence signal.
LLMSheriff does not replace existing observability stacks; it sits above them as an
experimental interpretation layer.

\subsection{Feature Extraction}

Each event contains a timestamp, step label, action string, duration, and status. Twelve
features are computed: runtime, average latency, LLM/tool/retry/failure counts, longest
repeated-action streak, a progress score (success rate penalised for non-waiting
repetition, capped at 1.0), waiting-action count/ratio (poll/status-check vocabulary),
and maximum/mean idle gaps. Idle-gap features separate tight work loops (Stalled) from
long-idle drift (Abandoned).

\subsection{Rule Engine and LLM Judge}

Rules are fast, deterministic, and explainable. They encode thresholds for failures,
waiting polls, tight loops, recovery after errors, and abandonment-like idle drift. The
LLM judge (NVIDIA Nemotron~\cite{nimotron}) receives the full trace and metrics and
returns a structured state prediction; a local heuristic fallback is used if the API
fails. Rules struggle on borderline cases; the LLM can reason about action semantics but
is slower, API-dependent, and less stable.

\subsection{Agreement Logic}

If both analyzers predict the same state, the system reports higher confidence. If they
disagree (e.g., rule $=$ Waiting, LLM $=$ Stalled), LLMSheriff does \emph{not} silently
pick a winner. It surfaces low confidence and recommends human inspection. This
disagreement-as-signal design is central to the contribution.

\subsection{State Vocabulary}

We use eight coarse behavioral states. Definitions are operational (observable from
traces), not claims about hidden mental states:

\begin{itemize}
\item \textbf{Planning:} the agent is organising next steps before substantial tool work.
\item \textbf{Executing:} the agent is making varied, goal-directed progress.
\item \textbf{Waiting:} the agent is polling or idle on an external dependency rather than
      doing productive local work.
\item \textbf{Recovering:} after failures or setbacks, the agent changes strategy and
      continues toward the goal.
\item \textbf{Stalled:} the agent repeats tight, low-diversity work without progressing
      (busy but unproductive).
\item \textbf{Abandoned:} long idle gaps and drift suggest the goal is no longer being
      pursued.
\item \textbf{Completed:} the trace indicates successful goal termination.
\item \textbf{Failed:} the trace indicates explicit unsuccessful termination.
\end{itemize}

\noindent Distinguishing \emph{Waiting} from \emph{Stalled} and \emph{Abandoned} is
central: waiting may be legitimate; stalled and abandoned motivate intervention.

\subsection{Implementation Note}

A FastAPI backend and Next.js dashboard visualise dual predictions, evidence,
disagreement, and intervention recommendations. The dashboard supports exploration; it is
not the research contribution. Reproducible evaluation scripts live in
\texttt{backend/scripts/}.

\section{Evaluation}

\subsection{Dataset and Protocol}

Because no public benchmark exists for agent intent-state labelling, we constructed a
reproducible synthetic corpus of 100 traces (20 each for Completed, Recovering, Waiting,
Stalled, and Abandoned). Generators vary timestamps, action diversity, failures,
repetition, and idle structure while preserving class semantics. \textbf{Important:} rule
thresholds were hand-tuned with knowledge of these generator families. High rule accuracy
therefore demonstrates feasibility on controlled synthetic trajectories; it should not be
read as production generalisability. Evaluation scripts are in the repository.

\subsection{Metrics}

We report accuracy and macro-F1 against synthetic gold labels, plus agreement rate and
conditional accuracy when analyzers agree or disagree.

\subsection{Evidence for H2 (Agreement as Confidence)}
\label{sec:h2}

Table~\ref{tab:agree} is the primary H2 result. Agreement occurred on 64/100 traces
(64\%). When analyzers agreed, accuracy relative to synthetic gold was \textbf{98.4\%}
(63/64); the single agree-but-wrong case was a Stalled trace where both predicted
Executing after an LLM parse fallback. When they disagreed ($n{=}36$), the rule engine was
correct on 91.7\% of cases and the LLM on 8.3\%.

Disagreements concentrated on Abandoned$\rightarrow$Stalled by the LLM ($n{=}20$),

complementary strengths, while high-volume Abandoned/Completed disagreements are mostly
rule-correct and LLM-wrong---still useful as review cues, not as automatic LLM overrides.

\section{Discussion}

\textbf{What works.} Waiting and idle-gap features removed a former systematic Waiting
failure mode. Dual inference makes uncertainty visible. On the primary run, agreement
accuracy is 98.4\%, and three of four rule Stalled misses are recovered by the LLM under
disagreement.

\textbf{What does not.} Rules are hand-tuned to generators; LLM alone is weaker and
systematically maps Abandoned to Stalled ($n{=}20$). Agreement is not infallible when the
LLM path falls back to heuristics. Synthetic evaluation cannot establish real-world
robustness. Human inter-rater validation of the state vocabulary remains future work.

\textbf{Scope of claims.} These experiments demonstrate feasibility of the approach on
controlled synthetic trajectories. Evaluation on real-world traces remains future work.

% -----------------------------------------------------------------------
\section{Limitations}

\begin{itemize}
\item Rule thresholds are hand-tuned on the synthetic generators.
\item The corpus is synthetic, not drawn from production agents.
\item Residual Stalled$\rightarrow$Executing errors show brittle thresholds.
\item LLM underperforms the tuned rule baseline alone; hybrid value is diagnostic, not
LLM dominance.
\item Hybrid API reliability: 14/100 judge calls used fallbacks in the primary run.
\item No completed human inter-rater $\kappa$ study is reported in this version.
\end{itemize}

% -----------------------------------------------------------------------
\section{Conclusion}

LLMSheriff investigates hybrid behavioral state inference from agent execution traces,
with agreement/disagreement as an interpretable confidence signal. On a controlled
synthetic evaluation, rules provide a strong baseline, the LLM contributes complementary
signals on uncertain cases, and agreement relative to synthetic labels is strong
(98.4\% accuracy on the agreement subset in the primary run).
The work is exploratory and scoped to the evaluation performed. Future work includes
real-world traces, human agreement studies, calibrated learning of thresholds, and broader
baselines---improvements that can position the approach for stronger venues after this
programme submission.
